# 山城连接 · 重庆大学校园网看板

Windows 托盘小程序，管理当前电脑的校园网连接。常驻右下角通知区域，无独立窗口、不启动 HTTP 服务、不依赖浏览器或 WebView，除 Python 标准库外无任何第三方依赖。

## 使用

推荐直接双击 **`dist/CQU-Net-Switch.exe`**。这是单文件程序，无需安装 Python，也不需要管理员权限。可以把这个 exe 单独复制到其他文件夹。也可双击 `启动.bat`（优先运行打包版本）。

从源码运行需要 Python 3.10+：

```powershell
python tray.py
```

启动后只在右下角托盘显示一个圆点图标：绿色表示校园网已连接，灰色表示未登录或状态未知，橙色表示正在切换连接。退出程序（托盘菜单“退出”）不会注销校园网。切换过程中需等待操作完成后才能退出。程序限制为同一 Windows 会话单实例。

- **右键点击托盘图标**弹出菜单：顶部显示当前连接状态，下方列出已保存账号（当前在线账号带勾选），点选即切换；另有“刷新状态”“断开当前连接”“开机自动启动”（勾选状态，写入当前用户注册表 Run 键，无需管理员权限）“退出”。
- **左键点击**或菜单中的“管理面板”打开完整窗口：查看真实在线账号、姓名、IPv4、IPv6、MAC、门户累计流量和时长；添加、编辑、移除账号（账号后缀例如 T 需完整保留）；查看操作记录。关闭面板窗口只是隐藏，程序仍在托盘运行。
- 面板“在线终端”页签通过门户在线列表（只读）显示**当前账号在全部设备上的在线情况**：MAC、IPv4、上线时间、在线时长，以及本机/MAC 绑定/无感标记；不只限于本机。切换账号只影响本机，其他终端保持在线。
- 托盘每 30 秒自动查询一次状态，悬停图标可查看当前账号；切换开始、成功或失败都会通过系统通知反馈。
- 连接账号时，先查询状态；如已在线则注销并确认离线，再登录目标账号，核对实际在线账号后才显示成功。
- 当前账号已在线时不会重复注销；切换失败不自动回滚或循环重试，可手动选择账号重新连接。

## 数据与接口

桌面版账号保存在 `%LOCALAPPDATA%\CQU-Net-Switch\profiles.json`，密码使用 Windows DPAPI 当前用户加密。编辑时密码留空保留原密码。移动 exe 或更新版本不会清除账号。加密文件不能直接搬到另一台电脑或另一位 Windows 用户下使用。首次运行会尝试从程序旁或当前项目的 `data/profiles.json` 复制旧网页版本的账号，原文件保留；已有桌面版数据时不覆盖。

**导入导出（迁移到其他电脑）**：管理面板“账号管理”页提供“导出 / 导入”按钮。导出时自行设置一个导出密码，账号（含登录密码）经 PBKDF2-HMAC-SHA256 派生密钥加密并带完整性校验后写入 JSON 文件，可安全复制到其他电脑；导入时输入导出密码，文件被篡改或密码错误会明确失败，本机已有的账号自动跳过，导入的账号按当前 Windows 用户重新加密保存。导入完成后建议删除导出文件。

官方门户请求使用验证证书的 HTTPS，不通过环境代理；登录接口按门户协议发送 GET 参数，应用不记录这些 URL，也不跟随重定向。网络请求在后台线程执行，不阻塞窗口。

状态来自 `https://login.cqu.edu.cn/drcom/chkstatus`。每次操作先用本机 IP 读取 HTTPS 802 端口的 `eportal/portal/page/loadConfig`，再按学校下发的认证方式操作。当前配置为 Portal 认证（`login_method=1`）、账号前缀 `,0,` 和 MAC 绑定；登录调用 `eportal/portal/login`，注销按官方页面调用 `eportal/portal/mac/unbind`，仅解除当前账号在本机的 MAC 绑定，避免注销后立即自动重连。离线后才开始目标账号登录。

旧 `ACSetting` 接口会返回 `Logout succeed` 但本机仍在线，因此不再使用。直接 `/drcom/logout` 对当前 MAC 绑定连接返回 `no webmode`，也不作为当前配置的注销入口。认证失败立即显示门户返回的原因，保留在底部和操作记录中，不被自动刷新覆盖。响应支持 gzip、UTF-8、GBK/GB18030；JSONP 仅解析 JSON，不执行返回脚本。

门户 `a40.js` 将 `time` 显示为分钟，将 `flow / 1024` 显示为 MByte，因此看板以分钟和 KiB 解释原始数据，界面 GB/MB 按 1024 进制换算。数据标为**门户累计**，不假定属于本次连接或当月；不推测未核实的速率字段含义。查询失败显示“状态未知”，不等同于未登录，保留的设备地址标记为上次成功查询信息。

## 验证

```powershell
python -m unittest -v
python tray.py --self-test .qa/source-tray-smoke.json
python desktop.py --self-test .qa/source-desktop-smoke.json
```

自动测试使用模拟门户，覆盖托盘菜单模型、切换顺序、失败停止、目标账号核对、退出保护、DPAPI 保存、API 来源检查，不会注销真实网络。首次使用需在管理面板填写账号密码完成真实登录验证。

`--self-test <报告路径>` 在临时目录验证 DPAPI、托盘图标与 Tk 窗口控件；桌面版自检还会只读查询真实认证门户；不读取用户保存的账号，也不注销或登录。打包后的 exe 支持同一参数。报告所在目录需已存在。

## 重新打包

```powershell
.\build.ps1
```

脚本在项目内创建 `.venv-build`，使用固定版本的 PyInstaller，输出 `dist/CQU-Net-Switch.exe`。只分发 exe 即可，`build` 和 `.venv-build` 均是构建缓存。exe 图标来自 `assets/logo.svg`（重大钟塔 + 信号弧 + 山城两江元素）；`assets/build_icons.py` 按尺寸分档生成图标：16–40px 使用简化粗塔形（细节在小尺寸会糊），48px 以上使用完整设计，托盘图标为简化塔形配在线绿/离线灰/切换橙三色徽章（`assets/tray-*.ico`，资源缺失时回退到程序绘制的状态圆点），全部随 `--icon` / `--add-data` 打进 exe。托盘、菜单和系统通知通过 Win32 API（ctypes）实现，打包不引入任何第三方库；单文件版本启动时会把运行库解包到 Windows 临时目录，程序退出后清理；未使用 Electron、浏览器引擎或第三方 GUI 框架。

## 保留的网页版本

`python server.py` 仍可启动此前的网页版本，地址为 `http://127.0.0.1:8765`。网页版本仍使用项目内的 `data/profiles.json`，与桌面版首次迁移后独立保存。`core.py` 是二者共用的认证逻辑，`desktop.py` 即托盘版的管理面板窗口，打包 exe 不包含网页资源或 HTTP 服务。`python desktop.py` 也可单独运行独立窗口版。

这是本机非官方工具。它控制服务所在电脑的校园网连接，不代表其他设备或某账号全部在线终端的状态。
